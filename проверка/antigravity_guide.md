# Google Antigravity CLI

**Что это, зачем нужен, как запустить из РФ/РБ**

---

## Что это такое

**Antigravity CLI** (antigravity.google) — терминальный AI-помощник для кодинга на базе **Gemini** от Google. Пришёл на замену Gemini CLI в июне 2026.

По сути — аналог Claude Code, но от Google:

| | Claude Code | Antigravity CLI |
|---|---|---|
| Компания | Anthropic | Google |
| Модель | Claude Opus/Sonnet | Gemini 2.5 Pro |
| Роль | Основной инструмент | «Второе мнение» |

---

## Зачем нужен — «второе мнение»

Идея: Claude Code пишет код, а Antigravity (Gemini) **перепроверяет**.

```
Claude Code пишет код → Antigravity ревьюит → Исправляем если нашёл баг
```

Разные модели ловят разные ошибки. Gemini может заметить то, что Claude пропустил, и наоборот.

## Проблема с доступом

### Почему не работает даже с VPN

Google проверяет **4 уровня**, VPN решает только один:

| Проверка | VPN решает? |
|---|---|
| IP-адрес | Да |
| Регион Google-аккаунта | Нет — если аккаунт РФ/РБ, блок |
| Номер телефона | Нет — российские/белорусские номера не проходят |
| Способ оплаты | Нет — российские карты не принимаются |

> **Россия, Беларусь, Иран, Китай, КНДР — в списке заблокированных стран Google AI.**

## Как запустить

### Шаг 1. Google-аккаунт в поддерживаемом регионе

- Создать новый Google-аккаунт с включённым VPN (США/Европа)
- При регистрации указать страну — США или любая из ЕС
- Номер телефона — нужен номер поддерживаемой страны (eSIM-сервисы или виртуальный номер)

### Шаг 2. VPN

- Держать включённым при работе с Antigravity
- Сервер — та же страна, что в Google-аккаунте

### Шаг 3. Установка

- Убедиться что Node.js установлен
- `npm install -g @google/antigravity`
- Авторизоваться через «чистый» Google-аккаунт

> Бесплатный тариф включает достаточно запросов для ревью кода и «второго мнения».

## Как использовать вместе с Claude Code

### Рабочий процесс «второе мнение»

- **Основная работа** — в Claude Code (пишем код, рефакторим, деплоим)
- **Ревью** — открываем Antigravity в соседнем терминале, просим проверить написанный код
- Примеры запросов для Antigravity:
  - "Review this code for bugs and security issues"
  - "What would you improve in this implementation?"
  - "Check this component for accessibility problems"

> Два терминала рядом: в одном Claude Code работает, в другом Antigravity ревьюит. Не нужно переключаться — работают параллельно.
