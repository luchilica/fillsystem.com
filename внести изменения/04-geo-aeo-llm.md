# 04. GEO / AEO — видимость в ChatGPT, Perplexity, AI Overviews

## 4.1. Что сделано правильно

Это редкий случай — на сайте есть осознанная работа под LLM-выдачу.

**`robots.txt` явно пускает AI-краулеров:**
```
User-Agent: GPTBot          Allow: /
User-Agent: ChatGPT-User    Allow: /
User-Agent: ClaudeBot       Allow: /
User-Agent: PerplexityBot   Allow: /
User-Agent: Applebot-Extended Allow: /
```

**`/llms.txt` существует** и структурирован грамотно: описание, ICP, методология в 3 шага, полный прайс-лист с URL, команда, партнёры, все 14 статей с заголовками и путями, локация, контакт. По формату — образцовый файл.

**`FAQPage` на главной** (14 вопросов) **и на каждой из 7 страниц услуг** — это ровно та разметка, из которой LLM извлекают прямые ответы.

**`HowTo`** для процесса диагностики (3 шага) — тоже цитируемый формат.

Стиль текста, при всех претензиях из `03-content-ai.md`, **хорошо цитируется**: короткие декларативные предложения, явные списки, таблицы «протокол / что стандартизует / роль». LLM такое извлекает охотно.

## 4.2. Главная проблема GEO: `llms.txt` врёт про цены

Файл `/llms.txt` заявляет:

```
- Extended Diagnostic (from $1,400)
- Add-on Tool Build (from $1,100)
- IT Risk & Security (from $2,100)
- Process & Operations (from $3,700)
- AI & Process Automation (from $4,100)
- RevOps: CRM, Data & Reporting (from $5,100)
```

Главная страница в дефолтном состоянии показывает: **$1,700 / $1,300 / $2,500 / $4,400 / $4,900 / $6,100**.

Это худший из возможных вариантов расхождения. `llms.txt` — файл, созданный специально для того, чтобы модели брали из него факты **вместо** парсинга страницы. Следовательно:

- ChatGPT/Perplexity ответят пользователю «RevOps starts from $5,100»;
- пользователь придёт на главную и увидит $6,100;
- разница 20 %, и она возникает до первого контакта.

**Плюс к этому:** цена в `llms.txt` — это цена для команды в 25 человек. ICP компании — 50–250 человек. При 50 сотрудниках множитель `1 + (50−25)×0.02 = 1.5`, то есть RevOps стоит **$7,650**. AI-ассистент назовёт целевому клиенту цену, которая **на 33 % ниже** реальной.

## 4.3. `llms.txt` не покрыт локалями и не обновляется

- Один файл на все 4 локали, полностью на английском. Русско- и китайскоязычные запросы в LLM получат английские данные (не критично) — но и все URL в файле без префикса локали, то есть модель никогда не сошлётся на `/ru/...`.
- Нет `llms-full.txt` (расширенная версия с полными текстами) — это стандарт де-факто для второй ступени.
- Нет даты обновления в файле. Модель не может оценить свежесть.
- Отсутствуют секции, которые дают наибольшую цитируемость: **«Кому мы не подходим»** (на сайте она есть в FAQ и очень сильная), **«Чего мы не делаем»**, **«Гарантии ROI: нет, потому что…»**. Это ровно те формулировки, которые LLM любят цитировать как отстройку.

| Что | Есть | Комментарий |

## 4.5. Чего нет для попадания в AI-ответы по коммерческим запросам

LLM отвечают на вопросы вида «who does RevOps consulting for mid-market B2B», «how much does a CRM audit cost», «best operations consultant California». Для попадания в такой ответ нужны:

1. **Цитируемость сторонними источниками.** Проверено: `sameAs` содержит одну ссылку. Нет профилей на Clutch, G2, UpCity, The Manifest, Crunchbase — площадках, которые LLM используют как справочники по консалтингу. Это главный дефицит: модель не может подтвердить существование компании независимым источником.
2. **Отзывы с именами.** Ноль на сайте, ноль вовне.
3. **Явные ценовые «якоря» в тексте.** Есть, но противоречивые (см. §4.2).
4. **Страница кейсов с URL.** Нет — только якорь `/#proof-examples`. LLM не может сослаться на кейс, у него нет адреса.
5. **`max-image-preview:large`** — влияет на площадь в AI Overviews. Не выставлено.
6. **Свежесть.** Последняя публикация 29 июля 2026. `lastmod` в sitemap у всех 107 URL одинаковый (дата билда), `dateModified` = `datePublished`. Никаких сигналов актуальности.

## 4.6. Риск, а не только возможность

Полностью открытый `robots.txt` для GPTBot/ClaudeBot/PerplexityBot при текущем состоянии контента означает: **модели заберут в качестве фактов** и цены из `llms.txt` (заниженные на 20–33 %), и вымышленные кейсы с точными суммами ($180K, $320K), и авторов «Solutions Architect» / «AI & Data Lead».

Дисклеймер под кейсами («Scenarios reflect patterns from real diagnostic engagements… Figures represent the range of impact typically identified») при извлечении **отваливается** — LLM берёт цифру, а не примечание под ней. Пользователь получит «Fill System помогли компании на 80 человек найти $180K потерянной выручки» как утверждение о факте.

Это единственная находка аудита, где текущая конфигурация активно генерирует некорректные утверждения о компании во внешних системах.

## 4.7. Что делать по GEO — по приоритету

1. **Синхронизировать `llms.txt` с фактическими ценами** — сегодня. И решить, какая цена «настоящая»: базовая (как на `/services`) или расчётная (как на главной). Одна.
2. **Добавить в `llms.txt`** секции «Not a fit for», «What we don't do», «No ROI guarantees — why», дату обновления и локализованные URL. Собирать файл из того же источника данных, что и страницы, чтобы расхождение стало невозможным.
3. **Продублировать `FAQPage`** на `/ru`, `/es`, `/zh-hans`.
4. **Сделать страницу кейсов по адресу** `/case-studies` (или `/results`) с отдельными URL под каждый сценарий и явной пометкой «иллюстративный сценарий» **в теле** каждого блока, а не одной строкой внизу секции.
5. **Завести внешние подтверждения сущности**: корпоративный LinkedIn, Crunchbase, Clutch. Добавить их в `Organization.sameAs`.
6. **Консолидировать `Person`** через `@id` на всех страницах.
7. **Выставить** `max-image-preview:large, max-snippet:-1`.
8. **Поставить реальные `dateModified`** и живой `lastmod`.
